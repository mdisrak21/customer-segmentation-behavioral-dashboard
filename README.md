# Progree Task 3 — Customer Segmentation & Behavioral Trend Dashboard

## Project Overview

This project was completed as part of the **Progree Data Analytics Internship — Task 3**.

The objective of this task is to design an interactive business intelligence dashboard that identifies distinct customer behaviors using **RFM (Recency, Frequency, Monetary) analysis**, cohort analysis, and geographic analysis.

The cleaned customer-level datasets were prepared in Python and exported for visualization in **Microsoft Power BI**.

---

## Objective

Design an interactive data portal to isolate distinct consumer behaviors by:

- Computing customer-level **Recency, Frequency, and Monetary (RFM)** metrics
- Creating meaningful customer segments based on RFM behavior
- Exporting clean analytical datasets for Power BI
- Building interactive charts and filters
- Performing customer cohort retention analysis
- Creating a geographic revenue analysis with country-level filtering

---

## Data Preparation

The transaction data was prepared before importing it into Power BI.

Main preparation steps:

1. Loaded the Online Retail II transaction data.
2. Removed exact duplicate records.
3. Excluded cancellation transactions for customer behavioral analysis.
4. Removed transactions with non-positive quantities or prices.
5. Calculated transaction revenue as:

`Revenue = Quantity × UnitPrice`

6. Retained valid customer transactions for customer-level analysis.
7. Calculated customer-level RFM metrics.
8. Prepared cohort and country-level summary datasets.
9. Exported clean analytical structures as CSV files.

## RFM Analysis

Customer behavior was measured using three standard RFM metrics:

### Recency

Number of days since the customer's most recent purchase relative to the analysis snapshot date.

### Frequency

Number of unique orders placed by the customer.

### Monetary

Total revenue generated by the customer.

These metrics were combined to create customer behavioral segments.

### Customer Segments

The project includes the following customer segments:

- Champions
- Loyal Customers
- Recent Customers
- Potential Loyalists
- At Risk
- Hibernating
- Needs Attention
